# Assignment 3.4 Create a new Markdown file
## Advantage of using Markdown
* An advantage of using Markdown is it is a simple plain text file that does not have complicated formatting.
* Markdown can also be used for a variety of operating systems and web applications.
[source: markdownguide.org](https://www.markdownguide.org/getting-started/)
## Limitation of using Markdown
* A limitation of using Markdown is that it may not reflect the branding of the organization that is using it. 
* Some people may also need training to use Markdown if it is new to them.
## Advice for getting started using Markdown
*Use cheat sheets online, such as [this Markdown Cheatsheet on Github](https://github.com/adam-p/markdown-here/wiki/Markdown-Cheatsheet#headers).
